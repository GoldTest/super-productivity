# Super Productivity 桌面悬浮小部件 (Super Focus Desktop Widget)

专注于桌面悬浮、贴边吸附与收起、按项目分 Tab 列表展示、番茄钟专注计时与自动提醒的独立桌面伴侣小部件。基于 Super Productivity 官方提供的 **Local REST API** 构建。

---

## 🌟 核心特性与最新功能

- **贴边自动收起为小横条 (Mini Bar)**：
  - 拖拽小部件贴边后，鼠标移开约 500ms 自动平滑收起为精致小横条（高约 44px）。
  - **鼠标挪回横条即刻展开** 为完整任务面板，操作流畅自然。
  - 在小横条内实时展示：当前专注的任务名称（🎯）、倒计时时长（⏱️）、开始/暂停按钮与展开图标。
- **纯粹直观的项目 Tab（去除全部与标签）**：
  - 去除冗余的“全部”和“标签”Tab。
  - 第一栏为 **📅 今日**，紧接着直接展示主程序中的 **各个项目 Tab**（`📂 工作任务`、`📂 学习计划` 等）。
  - 水平平滑滑动，一键快速在项目间切换。
- **智能场景化新增任务**：
  - 在 **今日 Tab** 下添加任务，自动为任务打上今日（`TODAY`）标签。
  - 在 **特定项目 Tab** 下添加任务，自动归属到当前对应的项目中。
- **一键点击开始专注**：
  - 列表中的每条任务均带有 ▶ 快捷播放按钮，点击后立即切换为当前专注任务并启动计时，无论展开态还是贴边收起的小横条均实时联动。
- **专注番茄钟与自动提醒**：
  - 内置 25 分钟专注 + 5 分钟休息循环，支持重置与跳过。
  - 倒计时结束时触发 Web Audio 合成提示铃声、系统桌面通知（Desktop Notification）与界面 Toast 提示。
- **无底边阴影与纯粹磨砂美学**：
  - 去除窗口底部阴影杂边，窗口边缘利落清晰。
  - 采用亚克力毛玻璃拟物风格（`backdrop-filter: blur(28px)`），支持实时透明度调节（35% ~ 100%）。
- **智能探测与双向同步**：
  - 自动识别本机 `%APPDATA%/superProductivity/local-rest-api-token` 访问凭证，开箱即连。
  - 主程序未启动时自动进入离线演示模式，保证功能可随时体验。

## 🚀 启动方式

### 方式 1：双击运行（Windows 最简）
直接双击运行目录下的：
```
desktop-widget/start.bat
```

### 方式 2：命令行运行
在 `desktop-widget` 目录下运行：
```bash
npm start
```
或者在项目根目录下运行：
```bash
npm run widget
```

---

## ⚙️ 如何连接 Super Productivity

1. 打开 **Super Productivity** 主程序。
2. 进入 **设置 (Settings) -> 自动与集成 (Integrations) -> 本地 REST API (Local REST API)** 并开启服务（默认端口 3876）。
3. 启动小部件即可自动识别 Token 并建立连接（左上角状态圆点变为 🟢 绿色）。
4. 也可点击小部件右上角 **⚙️ 设置** 手动配置或点击 **“⚡ 自动检测”**。
